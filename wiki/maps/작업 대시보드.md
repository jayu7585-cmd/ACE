# 작업 대시보드

> 상위: [[홈]] · Dataview가 자동으로 채운다. Claude가 직접 고치는 페이지가 아니다.
> 미처리 원자료는 Claude Code에서 `/wiki-ingest`를 인자 없이 실행하면 볼 수 있다.

## MOC 미배정 페이지
MOC에 아직 소속되지 않은 지식 페이지. 다음 ingest나 lint 때 Claude가 배정한다.
```dataview
TABLE type AS "유형", status AS "상태", updated AS "갱신"
FROM "wiki"
WHERE contains(list("concept", "theory", "topic", "person", "application", "synthesis"), type)
  AND (!moc OR length(moc) = 0)
SORT updated DESC
```

## 보강이 필요한 초안 (seed)
```dataview
TABLE type AS "유형", sources AS "출처", updated AS "갱신"
FROM "wiki"
WHERE status = "seed" AND type != "moc" AND type != "dashboard" AND type != "overview"
SORT sources ASC, updated ASC
```

## 근거가 가장 많이 쌓인 페이지
```dataview
TABLE type AS "유형", sources AS "출처", status AS "상태"
FROM "wiki"
WHERE sources > 0 AND type != "source"
SORT sources DESC
LIMIT 15
```

## 최근 종합·적용
```dataview
TABLE question AS "질문", created AS "작성"
FROM "wiki/syntheses" OR "wiki/applications"
SORT created DESC
LIMIT 10
```

## 미해결 상충·열린 질문
Dataview 설정에서 **Enable JavaScript Queries**를 켜야 보인다.
```dataviewjs
const rows = [];
for (const p of dv.pages('"wiki"')) {
  if (["index", "log"].includes(p.file.name)) continue;
  const text = await dv.io.load(p.file.path);
  const w = (text.match(/\[!warning\]/g) || []).length;
  const q = (text.match(/\[!question\]/g) || []).length;
  if (w || q) rows.push([p.file.link, w, q]);
}
dv.table(["페이지", "상충", "열린 질문"], rows.sort((a, b) => b[1] - a[1] || b[2] - a[2]));
```
